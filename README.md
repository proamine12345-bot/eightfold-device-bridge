# Eightfold Device Bridge

انشأ تطبيق apk Android حقيقي جاهز لتنزيل كتالي عندما تدخل له تجد واجهة احترافية وكل احترافي وخاص بي تالي  عندما تدخل له وهو شغال بنت يعني خدام بإنترنيت تدخل له يطلع كود تلك كود يضظهر بي 8 أرقام لايمكن ان يتكرر رقم لهاتفين فقط خاص بهاتف واحد كل رقم يكون خاص بهاتفك لاتظهر اي كتابة او شيء يظهر فقط رقم وفي اسفل يظهر ادخل رقم اخر 

يعني عندما يكون تطبيق في هاد جهاز ويضغط  على ادخل رقم ويدخل رقم هاتف اخر يصير من داخل تطبيق يشاهد هاتف أخر يعني يمكن يدخل تطبيقات خاص به مواقع وغيرها للخاصة بهاتف اخر من داخل تطبيق ...
